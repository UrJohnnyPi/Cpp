#### 1.概念
* 一个程序至少有一个线程，这个线程称为主线程(main thread)，如果我们不显示地创建线程，那我们的程序就是只有主线程的单线程程序。
* 并发：两个或者更多的任务同时（同一时间段内）被要求执行。
* 单核（或称单CPU）计算机通过上下文切换（进程/线程切换）处理并发。
* 多核计算机可以处理并行。
* 每个进程都有一个主线程，进程启动时，主线程自动运行。
* 同步和互斥：

| 性质 | 同步 | 互斥 |
| :-: | :-: | :-: |
| 定义 | 同步是两个或多个进程为完成某一任务而协调工作次序，互传信号，相互制约，是进程对进程的直接制约 | 互斥则是：并不一定是为完成同一任务的各进程，因临界资源的互斥性，使得某一进程进入临界区后，其他与该进程不相关的进程，以资源为纽带而造成的制约关系（这一关系是：其他进程被限制进入临界区），即间接制约 |
| 临界资源 | 临界资源是：继续运行的权利 | 临界资源是：争夺的资源 |
| P、V操作 | thread1:P(S1)...V(S2);thread2:P(S2)...V(S1) | thread:P(S)..V(S) |
| P、V操作的含义 | thread1捕获了正在发生的S1事件，于是拥有了继续运行的权利（当然运行权利只能被1个进程占有）——>运行完成后，激活S2事件，S2事件发生，S1事件自动消亡；同理可知thread2。 | thread占有了某一资源，于是获权执行，执行完后，释放该资源。 |
| P、V操作中信号量S的含义 | S表示：XX怎么样了。（如：empty是缓冲区为空、apple是盘子里放了苹果）；S∈{0,1}，表示事件是否发生。 | S表示：XX。（如：mutex是缓冲区、door是出入口）；其值表示临界资源数。 |
* P操作、V操作伪代码：
```javascript
typedef struct{ //信号量结构体
	int value; //临界资源数
	struct List * L; //等待进程链表，存放等待该资源的进程句柄
} semaphore;

void P(semaphore S , HANDLE thread){
	S.value--; //调用P(S)的第一步就是资源数减1；若S.value小于0，表示当前进程申请资源失败，当前进程应被置入等待队列，阻塞原语被调用，且|S.value| = 等待中的进程数；若S.value>=0，则表示当前进程取得资源占有权，调用唤醒原语。
	if(S.value < 0){
		S.L->addNode(thread);
		block(S.L);
	} else run(thread);
}
void V(semaphore S , HANDLE thread){
	S.value++;
	if(S.value <= 0){
		S.L->removeNode(thread X in wait list);
		wakeup(X);
		run(X);
	}
}
```
* 死锁

| 属性 | 值 |
| :-: | :-: |
| 定义 | 所谓死锁，是指多个进程因竞争资源而造成的一种僵局（互相等待），若无外力作用，这些进程都将无法向前推进。在编程中，至少有两个线程、两个互斥量存在，才有可能造成死锁。即`thread_1`占有了`mutex_1`后又去请求`mutex_2`，同时，`thread_2`占有了`mutex_2`后又去请求`mutex_1`，两线程都不愿放弃已有的互斥量，进而造成死锁局面。 |
| 编程中的解决方案1 | 将两线程对互斥量的占有顺序统一，即在`thread_1`和`thread_2`中同时调整为`mutex_1.lock();mutex_2.lock();`或`mutex_2.lock();mutex_1.lock();`。 |
| 编程中的解决方案2 | 存在一种机制，可以保证：要么两个互斥量都锁住，要么两个互斥量都没锁住 |

#### 2.CreateThread函数和CloseHandle函数
* CreateThread 用于创建一个线程；CloseHandle用于关闭创建的线程句柄。
* 函数原型：
```javascript
HANDLE WINAPI CreateThread(
    LPSECURITY_ATTRIBUTES   lpThreadAttributes, //线程安全相关的属性，常置为NULL；指向SECURITY_ATTRIBUTES结构的指针，决定返回的句柄是否可被子进程继承，如果为NULL则表示返回的句柄不能被子进程继承。
    SIZE_T                  dwStackSize,        //新线程的初始化栈的大小，可设置为0；以字节单位
    LPTHREAD_START_ROUTINE  lpStartAddress,     //被线程执行的回调函数，也称为线程函数；指向一个函数指针；线程函数原型：DWORD WINAPI ThreadProc(LPVOID lpParameter); 
    LPVOID                  lpParameter,        //传入线程函数的参数，不需传递参数时为NULL
    DWORD                   dwCreationFlags,    //控制线程创建的标志；3种参数：0：线程创建后立即执行线程；CREATE_SUSPENDED：线程创建后进入就绪状态，直到线程被唤醒时才调用；STACK_SIZE_PARAM_IS_A_RESERVATION：dwStackSize 参数指定线程初始化栈的大小，如果STACK_SIZE_PARAM_IS_A_RESERVATION标志未指定，dwStackSize将会设为系统预留的值。
    LPDWORD                 lpThreadId          //传出参数，用于获得线程ID，如果为NULL则不返回线程ID
);
//如果线程创建成功，则返回这个新线程的句柄，否则返回NULL。如果线程创建失败，可通过GetLastError函数获得错误信息。

BOOL WINAPI CloseHandle(HANDLE hObject);        //关闭一个被打开的对象句柄
//如果函数执行成功则返回true(非0)，如果失败则返回false(0)，如果执行失败可调用GetLastError函数获得错误信息。
```

#### 3.实例1（线程函数运用，无Mutex）
```javascript
#include "stdafx.h" //stdafx.h中没有函数库，只是定义了一些环境参数，使得编译出来的程序能在32位的操作系统环境下运行。stdafx.h在C++中起到的作用是头文件预编译，即把C++工程中使用的MFC头文件预先编译，以后该工程编译时，直接使用预编译的结果，以加快编译速度。
#include <windows.h>
#include <iostream>

using namespace std;

#define NAME_LINE 40

//定义线程函数传入参数的结构体
typedef struct __THREAD_DATA {
	int nMaxNum;
	char strThreadName[NAME_LINE];
	__THREAD_DATA() : nMaxNum(0) { //构造函数初始化 
		memset(strThreadName , 0 , NAME_LINE * sizeof(char));
	}
} THREAD_DATA;

//线程函数
DWORD WINAPI ThreadProc(LPVOID lpParameter) {
	THREAD_DATA * pThreadData = (THREAD_DATA *)lpParameter;

	for (int i = 0 ; i < pThreadData->nMaxNum ; ++i) {
		cout << pThreadData->strThreadName << " --- " << i << endl;
		Sleep(100);
	}
	return 0L;
}

int main() {
	//初始化线程数据
	THREAD_DATA threadData1, threadData2;
	threadData1.nMaxNum = 5;
	strcpy(threadData1.strThreadName , "线程1");
	threadData2.nMaxNum = 10;
	strcpy(threadData2.strThreadName , "线程2");

	//创建第一个子线程
	HANDLE hThread1 = CreateThread(NULL , 0 , ThreadProc , &threadData1 , 0 , NULL);
	//创建第二个子线程
	HANDLE hThread2 = CreateThread(NULL , 0 , ThreadProc , &threadData2 , 0 , NULL);
	//关闭线程
	CloseHandle(hThread1);
	CloseHandle(hThread2);

	//主线程的执行路径
	for (int i = 0 ; i < 5 ; ++i) {
		cout << "主线程 === " << i << endl;
		Sleep(100);
	}

	system("pause");
	return 0;
}

//我们预期的效果是每输出一条语句后自动换行，但结果却并非都是这样。
//这是因为在线程执行时没有做同步处理。比如其输出结果的前两行是这样的：

//主线程 === 线程1 --- 0
//0线程2 --- 0

//主线程输出"主线程 ==="后时间片已用完，这时轮到子线程1输出；
//在子线程1输出"线程1 ---"后时间片也用完了，这时又轮到主线程执行输出"0"；
//之后又轮到子线程1输出"0"。

//为避免此类情况，使用互斥量Mutex。
//互斥量则要求哪个线程获取了该互斥量锁就由哪个线程释放。
```

#### 4.互斥量三函数
```javascript
（1）CreateMutex
HANDLE WINAPI CreateMutex(
    LPSECURITY_ATTRIBUTES lpMutexAttributes,        //线程安全相关的属性，常置为NULL；指向SECURITY_ATTRIBUTES结构的指针，决定返回的句柄是否可被子进程继承，如果为NULL则表示返回的句柄不能被子进程继承。
    BOOL                  bInitialOwner,            //创建Mutex时的当前线程是否拥有Mutex的所有权；若为TRUE则指定当前的创建线程为Mutex对象的所有者，其它线程访问需要先ReleaseMutex。
    LPCTSTR               lpName                    //Mutex的名称
);

（2）WaitForSingleObject的作用是等待一个指定的对象(如Mutex对象)，直到该对象处于非占用的状态(如Mutex对象被释放)或超出设定的时间间隔。
DWORD WINAPI WaitForSingleObject(
    HANDLE hHandle,                                 //要等待的指定对象的句柄
    DWORD  dwMilliseconds                           //超时间隔；如果dwMilliseconds为非0，则等待直到dwMilliseconds时间间隔用完或对象变为非占用的状态；如果dwMilliseconds 为INFINITE则表示无限等待，直到等待的对象处于非占用的状态。
);

（3）ReleaseMutex：释放所拥有的互斥对象
BOOL WINAPI ReleaseMutex(HANDLE hMutex);            //hMutex为释放的互斥对象的句柄。
```

#### 5.实例2（含Mutex）
```javascript
#include "stdafx.h"
#include <windows.h>
#include <iostream>

using namespace std;

#define NAME_LINE 40

//定义线程函数传入参数的结构体
typedef struct __THREAD_DATA {
	int nMaxNum;
	char strThreadName[NAME_LINE];
	__THREAD_DATA() : nMaxNum(0) {
		memset(strThreadName, 0, NAME_LINE * sizeof(char));
	}
} THREAD_DATA;

HANDLE g_hMutex = NULL; //定义互斥量（或称互斥锁、互斥对象） 

DWORD WINAPI ThreadProc(LPVOID lpParameter) {
	THREAD_DATA * pThreadData = (THREAD_DATA *)lpParameter;

	for (int i = 0 ; i < pThreadData->nMaxNum ; ++i) {
		//请求获得一个互斥量锁
		WaitForSingleObject(g_hMutex , INFINITE);
		
		//子进程实际内容 
		cout << pThreadData->strThreadName << " --- " << i << endl;
		Sleep(100);
		
		//释放互斥量锁
		ReleaseMutex(g_hMutex);
	}
	return 0L;
}

int main() {
	//于此创建互斥量并赋值给g_hMutex 
	g_hMutex = CreateMutex(NULL , FALSE , NULL);
	
	//子线程执行路径 
	THREAD_DATA threadData1 , threadData2;
	threadData1.nMaxNum = 5;
	strcpy(threadData1.strThreadName , "线程1");
	threadData2.nMaxNum = 10;
	strcpy(threadData2.strThreadName , "线程2");

	HANDLE hThread1 = CreateThread(NULL , 0 , ThreadProc , &threadData1 , 0 , NULL);
	HANDLE hThread2 = CreateThread(NULL , 0 , ThreadProc , &threadData2 , 0 , NULL);
	
	CloseHandle(hThread1);
	CloseHandle(hThread2);

	//主线程的执行路径
	for (int i = 0 ; i < 5 ; ++i) {
		//请求获得一个互斥量锁
		WaitForSingleObject(g_hMutex , INFINITE);
		
		//主进程实际内容 
		cout << "主线程 === " << i << endl;
		Sleep(100);
		
		//释放互斥量锁
		ReleaseMutex(g_hMutex);
	}
	system("pause");
	return 0;
}

//执行结果：
主线程 === 0
线程1 --- 0
线程2 --- 0
主线程 === 1
线程1 --- 1
线程2 --- 1
主线程 === 2
线程1 --- 2
线程2 --- 2
主线程 === 3
线程1 --- 3
线程2 --- 3
主线程 === 4
线程1 --- 4
线程2 --- 4
线程2 --- 5
线程2 --- 6
线程2 --- 7
线程2 --- 8
线程2 --- 9
//这个输出序是按照主线程——>最先被调用的子线程中——>次先被调用的子线程。
//例如：主线程首先获得Mutex，输出0，Sleep(100)即等待100ms后，释放Mutex——>线程1立即捕获Mutex，输出0，Sleep(100)后，释放Mutex——>线程2etc
```

//有500张从北京到赣州的火车票，在8个窗口同时出售，保证系统的稳定性和数据的原子性
****************************************************************************
SaleTickets.h代码：

#include "stdafx.h"
#include <string>
#include <windows.h>

using namespace std;

typedef struct __Ticket{ //票类 
	int ticketCount; //当前总票数 
	string ticketFrequency; //班次：“A-->B” 
	__Ticket() : ticketCount(0) , ticketFrequency(""){}
} Ticket;

typedef struct __Window{ //窗口类
	Ticket * ticketPtr; //窗口指向的票对象 
	string windowID; //窗口信息：“窗口n” 
	__Window() : ticketPtr(nullptr) , windowID(""){}

DWORD WINAPI saleTicket(LPVOID lpParameter);

****************************************************************************
SaleTickets.cpp代码：

#include "stdafx.h"
#include <windows.h>
#include <iostream>
#include <string>
#include "SaleTickets.h"

using namespace std;

extern HANDLE printMutex;

//售票程序
DWORD WINAPI saleTicket(LPVOID lpParameter) {
	Window * windowPtr = (Window *)lpParameter;
	Ticket * windowSaleTicketPtr = windowPtr->ticketPtr; //获取窗口指向的票对象

	while(windowSaleTicketPtr->ticketCount > 0) { //之所以用while，是因为一个窗口（线程）可以一直工作

		//如果票数不为0，才请求获得一个互斥量锁
		WaitForSingleObject(printMutex , INFINITE);

		if (windowSaleTicketPtr->ticketCount > 0) { //之所以这里有一个判断，是因为在等待g_hMutex时，票可能就被耗尽了
			cout << windowPtr->ticketFrequency << "出售第" << windowSaleTicketPtr->ticketCount -- << "的票 , ";
			if (windowSaleTicketPtr->ticketCount >= 0)
				cout << "出票成功 ! 剩余" << windowSaleTicketPtr->ticketCount << "张票 。 " << endl;
			else cout << "出票失败 ! 该票已售完 。 " << endl;
		}

		//释放互斥量锁
		ReleaseMutex(printMutex);
	}

	return 0L;
}

****************************************************************************
main.cpp代码：

#include "stdafx.h"
#include <iostream>

#include <windows.h>

using namespace std;

//售票系统
int main() {
	//（1）创建一个互斥量printMutex，用于在大屏幕上打印信息
	HANDLE printMutex = CreateMutex(NULL , false , NULL);

	//（2）初始化火车票
	Ticket ticket;
	ticket.ticketCount = 100; //初始化总票数 
	ticket.ticketFrequency = "北京-->柏林"; //初试化班次 
	
	//（3）初始化窗口信息 
	const int WINDOW_NUM = 8; //规定窗口数为8 
	Window window[WINDOW_NUM]; //设置window数组存储8个窗口的信息 
	HANDLE thread[WINDOW_NUM]; //8个线程：8个窗口对应8个线程，去执行类似的8个工作 
	
	//（4）从0~7，每一窗口执行各自的工作 
	for(int i = 0 ; i < WINDOW_NUM ; ++i) {
		
		//（4.1）窗口对象数组（存储窗口对象的数组）初始化操作 
		window[i].ticketPtr = &ticket; //窗口i指向的票对，这表示每一窗口都有控制总票数的权利 
		window[i].windowID = "窗口" + to_string(i);

		//（4.2）初始化子线程，子线程建立后，将调用saleTicket(&window[i]);
		thread[i] = CreateThread(NULL , 0 , saleTicket , &window[i] , 0 , NULL);

		//（4.3）主线程请求获得一个互斥量锁，用于向大屏幕打印子线程的出售信息 
		WaitForSingleObject(printMutex , INFINITE);
		cout << "**********" << endl << window[i].windowID << "开始出售 " << window[i].ticketPtr->ticketFrequency << " 的票..." << endl <<  "**********" << endl;
		ReleaseMutex(printMutex); //释放打印权
	}
	
	while(ticket.ticketCount);
	
	for(int i = 0 ; i < WINDOW_NUM ; ++i) CloseHandle(thread[i]);
	
	//main从CreateThread处分裂成子线程，但不影响主线程的执行。主线程继续执行，子进程也继续执行，
	//直到子进程自行结束或主进程调用CloseHandle。 

	return 0;
}
